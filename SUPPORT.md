# Support

Use [GitHub Discussions or Issues](https://github.com/Hai-qq/climadc/issues) for reproducible usage
questions and bug reports. Include the ClimaDC version, platform, command, minimal configuration,
and `verify-run --json` or `verify-suite --json` output when applicable. Remove credentials and
private data before posting.

For vulnerabilities, follow [`SECURITY.md`](SECURITY.md). The project does not provide emergency
operations support, production control guarantees, or private consulting through the issue tracker.
