# Security policy

## Supported versions

Until a stable release, security fixes are applied to the latest published Alpha only.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's private **Security** tab and select **Report a vulnerability** to create a [GitHub Security Advisory](https://github.com/Hai-qq/climadc/security/advisories/new).

Include affected versions, reproduction conditions, impact, and any suggested mitigation. Do not include real credentials, tokens, private datasets, or sensitive infrastructure details beyond what maintainers need to reproduce the issue.

GitHub Security Advisories are the project's only private vulnerability-reporting channel. No personal email or external intake address is designated.

## Scope

Reports about upstream services, datasets, or dependencies should also be sent to their respective maintainers. ClimaDC is an offline research framework and is not a production control system.
